# **App Name**: HealthFlow

## Core Features:

- Activity Tracking: Log various fitness activities like running, swimming, and cycling.
- Progress Visualization: Display progress with interactive charts and graphs.
- Goal Setting: Set daily or weekly fitness goals for steps, distance, or calories burned.
- Personalized Recommendations: Offer customized workout routines and health tips using user data as a tool. Powered by generative AI.
- User Authentication: Secure user accounts with login and registration features.
- BMI Calculation: Calculate and display the user's BMI based on their height and weight.
- Login Page: Allow users to log in using their username and password or Google account.
- BMI Feedback: Provide feedback to the user based on their BMI, suggesting next steps for improvement.

## Style Guidelines:

- Primary color: Energetic red (#FF0000) to reflect health and vitality.
- Background color: white (#FFFFFF) for a clean and calming feel.
- Accent color: Analogous red (#800000) for calls to action and progress indicators.
- Body and headline font: 'PT Sans' for a modern, readable interface.
- Use clear and recognizable icons to represent activities and progress.
- Responsive design for seamless access across devices.
- Smooth transitions and loading animations for a polished user experience.
- It should contain buttons
